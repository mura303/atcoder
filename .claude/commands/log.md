`log.md` に 1 行追記する。引数: $ARGUMENTS

## 手順

1. 引数を `コンテスト / 記号 / 結果 / (分類) / メモ` に分ける。
   結果は `自力AC` `解説AC` `未AC` のいずれか。擬似コードから実装した回は `自力AC(擬似)`。

2. **結果が `解説AC` か `未AC` なのに分類が無ければ、そこで 1 問だけ聞く。**
   `知識不足` `考察不足` `実装力不足` `速度不足` のどれか。
   ここを空にすると週次の診断が効かなくなるので、省略させない。
   結果が `自力AC` なら分類は不要。

3. 日付は `date +%F`、**タイトルは `bin/title <コンテスト> <記号>`** で取る。
   タイトルを手で書かないこと（表記が揺れると後で困る）。
   `bin/title` が失敗したらタイトル無しで書き、その旨を 1 行添える。

4. `log.md` の末尾に 1 行足す。書式:

   ```
   2026-09-06 ABC095 C — Half and Half  自力AC  ABの枚数だけ全探索した
   2026-09-07 ABC122 B — ATCoder  解説AC  [考察不足] 部分文字列の言い換えができなかった
   ```

   既存の行は書き換えない。追記だけ。

5. `git add log.md && git commit && git push`。コミットメッセージは日本語で 1 行。

6. `python3 bin/pick --dry-run` を実行し、**「対象:」の行だけ**を出して、
   次に何問残っているかを伝える。問題文は出さない。

7. 結果が `解説AC` だったら「**3 日後に再実装**」と 1 行伝える。
   解説 AC は「解けた」に数えない（`CLAUDE.md`）。
